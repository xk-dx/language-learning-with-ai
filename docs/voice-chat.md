# 语音对话功能说明

基于词表场景的多轮角色扮演口语对话，使用浏览器原生 API + DeepSeek AI 实现零成本练习。

## 技术原理

```
你说话 → 浏览器 SpeechRecognition (STT, 免费, 中英文混识)
       → DeepSeek AI (/api/chat, 多轮历史 + 角色提示词)
       → 浏览器 speechSynthesis (TTS, 免费, 英语朗读)
       → 语音回复 + 屏幕文字展示
```

| 环节             | 技术                                             | 成本                |
| ---------------- | ------------------------------------------------ | ------------------- |
| 语音转文字 (STT) | 浏览器 `SpeechRecognition` API（Web Speech API） | **免费**，中英文混识 |
| AI 对话          | DeepSeek（通过 `/api/chat`，带 20 轮历史上下文）  | 已有，按 token 计费 |
| 文字转语音 (TTS) | 浏览器 `speechSynthesis` API（Web Speech API）   | **免费**，英语朗读  |

## 角色扮演机制

选中词表后，AI 会根据词表的「场景」字段自动构建角色设定。

例如词表「旅行文化」（场景：机场、酒店、城市出行），AI 的提示词会变为：

> **你是一个英语口语陪练，你正在扮演"机场、酒店、城市出行"场景下的角色。**
> - 全程用英语交流，语速适中、用词简单
> - 你的角色是该场景中的对话者（如柜台人员、导游、司机等）
> - 用户扮演该场景中的另一个角色
> - 自然地使用词表中的单词：check-in, boarding, suitcase...
> - 每次回复 1-3 句，保持对话简短自然

## 前置条件

- **浏览器**：Chrome / Edge（完整支持 Web Speech API）
- **后端**：Flask 服务运行中（`python app.py`）
- **词表**：建议先创建一个带有场景说明的词表，或选中一个现有词表
- **麦克风**：浏览器需获取麦克风权限

## 使用方式

1. 打开前端 → 选中一个词表（场景设定会决定 AI 的角色）
2. 切换到「语音」Tab
3. 点击 **「🎤 开始对话」**
4. 浏览器请求麦克风权限 → 点击「允许」
5. 对着麦克风说英语（也可中英文混合）
6. AI 会扮演场景角色用英语回复，同时显示文字
7. 可继续对话（多轮上下文自动接续），或点击 **「⏹ 结束对话」** 停止

## 实现文件

- `frontend/src/App.tsx` — 语音对话组件：
  - `voiceSystemPrompt` — 根据词表场景动态生成角色提示词（含词表单词列表）
  - `sendToAgent()` — 发送多轮历史到 `/api/chat`，更新 `voiceHistory` 和 `voiceDisplay`
  - `startVoiceChat` / `stopVoiceChat` / `clearVoiceChat`
- `frontend/src/styles.css` — 语音对话样式（`.voice-messages` / `.voice-msg` / `.voice-status-dot`）
- `backend_flask/app.py` — `POST /api/chat` 端点（接受 `system` + `messages` 数组，保留 20 轮历史）

## 自定义 AI 角色

角色提示词由 `App.tsx` 中的 `voiceSystemPrompt` 动态生成。你可以修改这段代码来调整 AI 的行为：

- 改变语言：把提示词中的「全程用英语交流」改为「用中文回答」
- 改变角色风格：改为严肃的老师、幽默的朋友等
- 调整句子长度：修改「每次回复 1-3 句」中的数字
- 添加对话规则：例如「每次回复后问一个问题」保持对话进行

## 注意事项

- **首次使用**：浏览器会请求麦克风权限，需要在弹窗中点击「允许」
- **HTTPS**：`SpeechRecognition` 在非 localhost 环境下需要 HTTPS 才能工作
- **语音识别语言**：设为 `zh-CN`，可同时识别中文和英语单词；也可改为 `en-US` 只识别英语
- **语音合成语言**：设为 `en-US`（英语朗读），可改为 `zh-CN` 让 AI 用中文朗读
- **回退机制**：如果后端 `/api/chat` 不可用，会显示连接失败提示，不会崩溃
